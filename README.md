# Converting from .CSV to .JSON & vice versa.

## With this programme you can set the path to your own files and convert your files

## with .CSV format to a .JSON file and vice versa.

### Notice that there are some commented lines in which data is stored in the variable in a list.

### Whereas, in the following alternative part, data is stored in the variable in a dictionary.

### You can test the programme with the test files specified in the code.

### Some improvements like making it more interactive can be applied to it in future.
